# Lesson Adoption Updates

This document covers the steps that should be followed when adopting a lesson into the official curriculum.

Step 1
- review the lesson using the checklist ( https://github.com/carpentries-lab/reviews/blob/main/docs/reviewer_guide.md#reviewer-checklist )

Step 2
- logistics of moving the lesson + Carpentries infrastructure

Step 3
- call for maintainers

Step 4
- public announcement
